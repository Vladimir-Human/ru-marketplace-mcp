## Ключевые изменения выпуска

Доктрина цены/числа (аудит циклов 24–43): каждый локальный парсер цен/счётчиков
приведён к общей гарантии «никогда 0, никогда отрицательная, никогда не-конечная,
никогда не бросает» и зафиксирован тестами на живых байтах:

- `_as_price` (compare) делегирован в `mcp_core.coerce_price`; фабрикация цены из
  range-строк устранена (доказано на живых строках Ozon).
- `_as_count` (compare), `ssr._to_number/_to_int` (yandex), `_kopeck_to_rub` (wb),
  `_posted_at` (avito), `coerce_rating`/`parse_retry_after` (mcp-core) — закрыты
  OverflowError/inf/знаковые дыры.
- Карточный экстрактор taobao: title из mainTitle, цена собирается из
  symbol/text-спанов, shop/sales скоуплены — 3 живых дрейфа починены.
- Фикстуры из живых снятий (с провенансом и sha256): ozon-поиск, taobao-карточка,
  lamoda-поиск, wb search/card, detmir card/category, megamarket-поиск.
- **raw-CDP fallback в mcp-core**: Chrome 151 перестал отвечать на
  connect_over_cdp-рукопожатие Playwright (проверено на 1.61 и 1.62); транспорт
  теперь при таймауте attach'а ведёт вкладку по сырому CDP. Поведение на старых
  Chrome не изменено (Playwright-путь байт-в-байт прежний). Это вернуло к работе
  все CDP-источники на свежем Chrome: doctor показывает 6 healthy вместо 3.
- Все 45 инструментов несут секции `## Return Format` и `## Error Format`,
  видимые в живом маунте (griffe обрезает описание после `Args:` — секции
  перенесены перед ним); структурный тест пинит наличие секций.
- WB-скилл переписан под живое измерение разрыва search-vs-card.

## Известные ограничения выпуска

- Playwright ≤ 1.62 не завершает attach с Chrome 151 — закрыт raw-CDP fallback'ом
  в этом выпуске; при появлении совместимой версии Playwright fallback просто не
  сработает (поведение не изменится).
- Avito/DNS/Megamarket блокируют текущую сессию/сеть — снятые фикстуры фиксируют
  парсеры, живые selfcheck'и сообщают честные вердикты.
- MPStats требует платного токена — опциональный источник.
- Разрыв цен WB search-vs-card неустраним на стороне коннектора (протухание
  индекса WB) — защита «цитируй wb_card, сверяй до победителя» встроена в скилл.
