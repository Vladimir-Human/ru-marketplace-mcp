### Added
- В `source_outcomes` ответа `compare_prices` у каждого магазина появились `observed_at` (время в UTC, когда сравнение получило ответ магазина) и `region` (регион, который называет сам ответ поиска; сейчас только Авито: id локации, по которой шёл поиск). Если ответившие магазины назвали разные регионы, сравнение добавит заметку `info:mixed_regions`. Ранжирование от региона не меняется (#282).
- `compare_prices` source outcomes gain `observed_at` (UTC time when the comparison received the source's answer) and `region` (the region the search answer itself names; today only Avito: the location id the search ran against). If answering sources name different regions, the comparison adds an `info:mixed_regions` note. The ranking does not change with the region (#282).
