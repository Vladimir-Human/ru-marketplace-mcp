### Fixed
- Проверка предложения: `compare_verify_offer` для Яндекс Маркета принимает ссылку на предложение из ответа `compare_prices` (`market.yandex.ru/card/<название>/<номер>`). Раньше такой вызов кончался ошибкой `bad_request`, потому что карточка Маркета берёт только номер (#322).
- Offer verification: `compare_verify_offer` for Yandex Market accepts the offer url `compare_prices` returned (`market.yandex.ru/card/<slug>/<id>`). Such a call used to end in `bad_request`, because the Market card takes the numeric id only (#322).
