### Fixed
- Проверка предложения: `compare_verify_offer` для Яндекс Маркета принимает ссылки на предложения из ответа `compare_prices` (`market.yandex.ru/card/<название>/<номер>`, `/product/<номер>?...` и `/product--<название>/<номер>`). Раньше такой вызов кончался ошибкой `bad_request`, потому что карточка Маркета берёт только номер (#322).
- Offer verification: `compare_verify_offer` for Yandex Market accepts the offer URLs `compare_prices` returns (`market.yandex.ru/card/<slug>/<id>`, `/product/<id>?...`, and `/product--<slug>/<id>`). Such a call used to end in `bad_request`, because the Market card takes the numeric id only (#322).
