### Added
- CLI (`marketplace-mcp install` и `setup`): добавлена поддержка клиентов `vscode` (корневой ключ `"servers"` и `"type": "stdio"` в `Code/User/mcp.json`), `windsurf`, `antigravity`, `gemini` и `codex` (`codex mcp add`) (#333).
- CLI (`marketplace-mcp install` and `setup`): added client targets `vscode` (`"servers"` root key with `"type": "stdio"` in `Code/User/mcp.json`), `windsurf`, `antigravity`, `gemini`, and `codex` (`codex mcp add`) (#333).

### Fixed
- DNS-Shop: в новом профиле браузера первая страница поиска без цен загружается ещё один раз (и только тогда); ссылки вида `/product/analog/<id>/<slug>/` в выдаче и в `dns_card` больше не превращаются в фиктивный идентификатор `"analog"`, карточка товара читает цену и наличие только из основного блока `.product-card-top` без блоков рекомендаций и аксессуаров (распознавая «Товар распродан»), страницы 404 возвращают `not_found`, а неполные ответы с `healthy=false` не попадают в кэш (#333).
- AliExpress: у товаров с длинным названием (больше 140 знаков) заголовком остаётся само название (а не строка карточки вроде «до 10 дней, бесплатно» или «20 купили»), строки купонов не попадают в название, платная доставка и надбавки `+ N ₽` не выбираются как цена товара, одиночные цифры без десятичной части не читаются как рейтинг, счётчик заказов на карточке понимает формы «1 заказ» и «24 заказа», а обычные информационные пометки о купонах и лимите в 48 карточек помечены `info:` и оставляют ответ `healthy=true` (#333).
- Wildberries и Ozon: схема `wb_category_products.query` расширена до 1000 символов (для длинных селекторов `subject=...` из меню WB), DOM-парсер WB отфильтровывает бейджи «за отзыв», «частями», пошлины, доставку и надбавки со знаком `+`/`—` и повторно проверяет кэш внутри `_dom_lock`, `ozon_card` на карточках нет в наличии (`webPrice.isAvailable=false`) больше не оставляет старую цену из `webSale` независимо от порядка виджетов и проверяет `instock_no_price`, а пустой запрос `ozon_search` сразу возвращает `bad_request` (#333).
- Яндекс Маркет и Ситилинк: парсер Яндекс Маркета корректно разбирает массивы JSON-LD, вложенные `brand`/`image` и проверяет хосты ссылок через `page_link`, ответы HTTP 403 без капчи классифицируются как `transport_down` вместо ложного `parser_drift`, а карточка Ситилинка проверяет блок покупки и кнопку корзины строго вне блоков рекомендаций и исправляет описания `product_id` (#333).
- CLI, CDP и запуск браузера: в `doctor` следующий шаг называет `unblock`, если одна из проверок наткнулась на защиту сайта (даже когда другую отклонил лимит запросов), а для браузерного источника при доступном Chrome и незагрузившейся странице советует `unblock <источник>`; при `WB_TRANSPORT=dom` команды `unblock` и `setup` поддерживают `wildberries`, `unblock --wait` отклоняет `nan`/`inf`, `setup` сохраняет напоминание `claude mcp add` при нескольких клиентах, поиск браузера на Windows ставит пользовательский Chrome выше Edge и находит 32-битный путь Edge, а навигация Playwright в `chrome_cdp` сразу прерывает подвисшие ответы HTTP 429 до `commit` и подтверждает закрытие вкладки при отмене (#333).
- DNS-Shop: on a new browser profile a first search page rendered before prices is loaded once more (and only then); `/product/analog/<id>/<slug>/` links in search and `dns_card` now extract the real 16-hex product ID instead of `"analog"`, card extraction scopes prices and stock to `.product-card-top` away from recommendation/accessory rails (recognizing «Товар распродан»), 404 pages map to `not_found`, and unhealthy responses are not cached (#333).
- AliExpress: products with long names (over 140 characters) keep their real title instead of tile metadata lines ("до 10 дней, бесплатно", "20 купили"), coupon labels no longer leak into item titles, paid delivery and `+ N ₽` surcharge leaves are excluded from item prices, bare integers without decimals are not read as star ratings, card order counts match singular/paucal Russian forms, and routine `truncated_at_48` / coupon notices use `info:` so normal searches stay `healthy=true` (#333).
- Wildberries and Ozon: raised `wb_category_products.query` schema `max_length` to 1000 to match menu `subject=...` selectors, filtered review-reward/split/duty/shipping/`+`/`—` surcharge decoy lines and rechecked `_dom_cache` inside `_dom_lock` in WB DOM mode, made `ozon_card` `_parse_widgets` order-independent so `webSale` prices are cleared whenever `webPrice.isAvailable` is `false` while wiring `instock_no_price`, and rejected blank `ozon_search` queries as `bad_request` before opening Chrome (#333).
- Yandex Market and Citilink: handled JSON-array `ld+json` blocks, nested `brand`/`image` values, `page_link` URL host validation, HTTP 403 non-captcha refusal classification (`transport_down` instead of false `parser_drift`), `raise_tool_error_from` error wrapping, and Citilink `buyBlock`/`basketBtn` stock checks scoped away from recommendation rails plus `product_id` schema descriptions (#333).
- CLI, CDP, and browser discovery: `doctor` now prioritizes `unblock` when a check hits site protection even if the live budget refused another check, and advises `unblock <source>` when a browser-backed page fails to load while Chrome answers; enabled `marketplace-mcp unblock wildberries` under `WB_TRANSPORT=dom`, guarded `unblock --wait` against `nan`/`inf`, kept the `claude mcp add` reminder when `setup` configures multiple clients, ranked `%LOCALAPPDATA%` Chrome ahead of Edge while adding `Program Files (x86)` Edge on Windows, and made Playwright CDP navigation fail fast on stalled HTTP 429 responses before `commit` with shielded target-close confirmation (#333).

### Security
- Зависимости: минимальная версия `fastmcp` поднята до `>=4.2.1,<5` во всех пакетах и в `uv.lock` (`4.2.1` закрывает проверку `nbf` в JWT и поднимает порог `opentelemetry-api` выше `CVE-2026-126360`) (#333).
- Dependencies: bumped `fastmcp` floor to `>=4.2.1,<5` across workspace packages and `uv.lock` (`4.2.1` enforces future-`nbf` JWT rejection and raises the `opentelemetry-api` floor past `CVE-2026-126360`) (#333).
