### Added
- Настройка `AVITO_MAX_PHOTOS` (от 0 до 10, по умолчанию 3) задаёт, сколько фото объявления может приложить `avito_card(photos=N)`; без неё всё как раньше (#343).
- `AVITO_MAX_PHOTOS` (0 to 10, default 3) sets how many listing photos `avito_card(photos=N)` may attach; unset, nothing changes (#343).
