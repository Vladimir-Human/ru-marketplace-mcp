### Fixed
- Браузер: вкладка или всплывающее окно товара, которые сервер открыл через запасной путь (raw CDP) и на которые площадка ответила отказом 429 с недописанной страницей, больше не остаются открытыми в Chrome. Chrome иногда отвечал «закрыто» и оставлял вкладку; теперь сервер проверяет, что вкладки нет, и при необходимости закрывает её ещё раз (#317).
- Browser: a tab or item popup the server opened through its fallback path (raw CDP), refused with a 429 whose page never finished, no longer stays open in Chrome. Chrome sometimes answered "closed" and kept the tab; the server now checks the tab is gone and closes it again if needed (#317).
