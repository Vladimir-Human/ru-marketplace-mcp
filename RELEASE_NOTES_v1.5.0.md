## Что вошло в релиз

### Добавлено

- **Бандл DeepSeek Harness в `dsh/`.** 13 Agent Skills доступны сразу; две
  MCP-строки (`compare-mcp` и `marketplace-mcp`) выключены по умолчанию и
  включаются переменной `RU_MARKETPLACE_MCP_DIR` с путём к клону.
  `RU_MARKETPLACE_MCP_FULL` переключает режим с рекомендуемого сравнения цен
  на полный сервер. Установка:
  `dsh plugin --profile web add github:Vladimir-Human/ru-marketplace-mcp#path:/dsh`.
- **Таргет `dsh` в `marketplace-mcp install`.** Печатает готовый
  `cordis.patch.yml`-блок с выключенными строками, а не JSON `mcpServers`.
- **Гейты бандла.** `test_dsh_bundle.py` сверяет вендор скиллов с источником
  и доказывает, что ловит дрейф; новая работа CI ставит бандл в чистый
  профиль и утверждает состав `dsh.profile.bundles`, наличие 13 скиллов,
  disabled-состояние обеих строк и откат через `remove`.

### Изменено

- **Выходные схемы сжаты до имён полей верхнего уровня.** Стоимость
  `marketplace-mcp` упала с ~38 078 до ~13 020 токенов на каждый запрос,
  `compare-mcp` — с ~2 424 до ~918 (измерено `scripts/mcp_wire.py` по
  реальному MCP-проводу). Полевые описания остались в `## Return Format`
  описаний инструментов; имена полей по-прежнему закреплены
  `public_contract.json`.
- **11 `*_selfcheck` ушли с MCP-поверхности.** Они остались CLI-only и
  вызываются `marketplace-mcp doctor`. Модельный набор: 33 инструмента в
  двенадцати серверах, 34 в объединённом. Скиллы больше не предлагают
  агенту вызвать канарейки; тест паритета теперь требует, чтобы пункт под
  заголовком «Tools available» был настоящим MCP-инструментом.
- **Описания скиллов в лимите dsh.** `mpstats-connector` 591 → 476,
  `compare-prices` 500 → 449 символов.

### Исправлено

- `dsh/package.json` не попадал в git: общий ignore `package.json` съедал
  манифест бандла. Локально всё работало, CI checkout ломался; CI и поймал.
  Добавлено исключение `!dsh/package.json`.
- `scripts/e2e_stdio_check.py` и smoke-работа CI всё ещё ожидали счётчики
  поверхности до ухода selfcheck'ов (9/4/…/45 вместо 8/3/…/34). Исправлены.
